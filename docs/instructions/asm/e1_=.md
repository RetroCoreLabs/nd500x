# E1:= - Load Least Significant Part of Double Float Register E1 (D1)

## Overview

**Mnemonic:** `e1:=`
**Function:** Load least significant part of double float register D1 (E1)
**Class:** MOVE
**Privilege:** user

**Format:** `E1:= <operand>`

---

## Description

Loads the least significant 32 bits of the double float register D1 (referred to as E1) from the specified operand. This instruction is used for integer/float register communication, allowing data transfer between integer and float registers without performing any type conversion.

When a register is specified as an operand, the general integer registers (I1-I4) are used. Thus, this instruction can transfer data between integer and float registers directly.

The double float registers D1-D4 are 64-bit registers, composed of a most significant part (A1-A4) and least significant part (E1-E4). This instruction loads only the least significant 32 bits.

**Operands:** 1
**Variants:** 1 opcode(s)

## Operands

### Operand 1 (Source)

The source operand containing the 32-bit word to load into the least significant part of D1 (E1).

**Type:** Word (32-bit)
**Access:** Read

**Supported modes:**
- **LOCAL** - Local data area access (B.variable)
- **RECORD** - Record-relative access (R.field)
- **CONSTANT** - Immediate constant value
- **REGISTER** - Integer register (I1-I4)
- **PRE_INDEXED** - Indexed addressing with offset
- **ABSOLUTE** - Absolute memory address

---

## Trap Conditions

- **Addressing traps:** Invalid address, descriptor range violation, page fault, protection violation

---

## Data Status Bits

- **Z (Zero):** Set if source operand = 0, cleared otherwise
- **S (Sign):** Set to sign bit of source operand (bit 31)
- **O (Overflow):** Unaffected
- **K (Flag):** Unaffected
- **C (Carry):** Unaffected

---

## Examples

### Example 1: Load from local variable

```assembly
        % Load E1 (least significant part of D1) from local word
        E1:= B.LSW_VALUE
```

### Example 2: Load from integer register

```assembly
        % Transfer I2 to E1 without conversion
        E1:= I2
```

### Example 3: Construct double float from two words

```assembly
        % Build D1 from two separate words
        A1:= B.MSW            % Load most significant part
        E1:= B.LSW            % Load least significant part
```

### Example 4: Load immediate value

```assembly
        % Load E1 with specific bit pattern
        E1:= 012345678H       % Least significant bits of double
```

## Performance Notes

- **Typical cycles:** 2-4 cycles depending on addressing mode
- **Best case:** 2 cycles (register to register)
- **Worst case:** 4+ cycles (memory access with page fault)
