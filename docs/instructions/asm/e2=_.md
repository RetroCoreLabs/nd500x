# E2=: - Store Least Significant Part of Double Float Register E2 (D2)

## Overview

**Mnemonic:** `e2=:`
**Function:** Store least significant part of double float register D2 (E2)
**Class:** MOVE
**Privilege:** user

**Format:** `E2=: <operand>`

---

## Description

Stores the least significant 32 bits of the double float register D2 (referred to as E2) to the specified operand. This instruction is used for integer/float register communication, allowing data transfer between integer and float registers without performing any type conversion.

When a register is specified as an operand, the general integer registers (I1-I4) are used. Thus, this instruction can transfer data between float and integer registers directly.

The double float registers D1-D4 are 64-bit registers, composed of a most significant part (A1-A4) and least significant part (E1-E4). This instruction stores only the least significant 32 bits.

**Operands:** 1
**Variants:** 1 opcode(s)

## Operands

### Operand 1 (Destination)

The destination operand where the 32-bit least significant part of D2 (E2) will be stored.

**Type:** Word (32-bit)
**Access:** Write

**Supported modes:**
- **LOCAL** - Local data area access (B.variable)
- **RECORD** - Record-relative access (R.field)
- **REGISTER** - Integer register (I1-I4)
- **PRE_INDEXED** - Indexed addressing with offset
- **ABSOLUTE** - Absolute memory address

**Note:** CONSTANT mode is not allowed for destination operands.

---

## Trap Conditions

- **Addressing traps:** Invalid address, descriptor range violation, page fault, protection violation
- **Illegal operand specifier (IOS):** Attempting to use constant as destination

---

## Data Status Bits

- **Z (Zero):** Set if source register E2 = 0, cleared otherwise
- **S (Sign):** Set to sign bit of source register E2 (bit 31)
- **O (Overflow):** Unaffected
- **K (Flag):** Unaffected
- **C (Carry):** Unaffected

---

## Examples

### Example 1: Store to local variable

```assembly
        % Store E2 to local word
        E2=: B.LSW_OUTPUT
```

### Example 2: Store to integer register

```assembly
        % Transfer E2 to integer register I4 (no conversion)
        E2=: I4
```

### Example 3: Decompose double float

```assembly
        % Extract D2 into two 32-bit words
        A2=: B.HIGH_WORD      % Store most significant
        E2=: B.LOW_WORD       % Store least significant
```

### Example 4: Store to array

```assembly
        % Store E2 to array element
        E2=: B.BUFFER(I2)
```

---

## Performance Notes

- **Typical cycles:** 2-4 cycles depending on addressing mode
- **Best case:** 2 cycles (register to register)
- **Worst case:** 4+ cycles (memory access with page fault)
