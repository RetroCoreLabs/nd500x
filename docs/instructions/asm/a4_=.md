# A4:= - Load Most Significant Part of Double Float Register A4

## Overview

**Mnemonic:** `a4:=`
**Function:** Load most significant part of double float register A4
**Class:** MOVE
**Privilege:** user

**Format:** `A4:= <operand>`

---

## Description

Loads the most significant 32 bits of the double float register A4 from the specified operand. This instruction is used for integer/float register communication, allowing data transfer between integer and float registers without performing any type conversion.

When a register is specified as an operand, the general integer registers (I1-I4) are used. Thus, this instruction can transfer data between integer and float registers directly.

Note that a float register (A1-A4) is equivalent to the most significant part of a double float register (D1-D4), so A4:= loads the entire float register A4.

**Operands:** 1
**Variants:** 1 opcode(s)

## Operands

### Operand 1 (Source)

The source operand containing the 32-bit word to load into the most significant part of A4.

**Type:** Word (32-bit)
**Access:** Read

**Supported modes:**
- **LOCAL** - Local data area access (B.variable)
- **RECORD** - Record-relative access (R.field)
- **CONSTANT** - Immediate constant value
- **REGISTER** - Integer register (I1-I4)
- **PRE_INDEXED** - Indexed addressing with offset
- **ABSOLUTE** - Absolute memory address

---

## Trap Conditions

- **Addressing traps:** Invalid address, descriptor range violation, page fault, protection violation

---

## Data Status Bits

- **Z (Zero):** Set if source operand = 0, cleared otherwise
- **S (Sign):** Set to sign bit of source operand (bit 31)
- **O (Overflow):** Unaffected
- **K (Flag):** Unaffected
- **C (Carry):** Unaffected

---

## Examples

### Example 1: Load from local variable

```assembly
        % Load A4 from local word variable
        A4:= B.MULTIPLIER
```

### Example 2: Load from integer register

```assembly
        % Transfer I4 to A4 without conversion
        A4:= I4
```

### Example 3: Load from record field

```assembly
        % Load A4 from record field
        A4:= R.DATA_FIELD
```

### Example 4: Load immediate constant

```assembly
        % Load A4 with bit pattern
        A4:= 03FF00000H        % Specific float bit pattern
```

---

## Performance Notes

- **Typical cycles:** 2-4 cycles depending on addressing mode
- **Best case:** 2 cycles (register to register)
- **Worst case:** 4+ cycles (memory access with page fault)
