# E3:= - Load Least Significant Part of Double Float Register E3 (D3)

## Overview

**Mnemonic:** `e3:=`
**Function:** Load least significant part of double float register D3 (E3)
**Class:** MOVE
**Privilege:** user

**Format:** `E3:= <operand>`

---

## Description

Loads the least significant 32 bits of the double float register D3 (referred to as E3) from the specified operand. This instruction is used for integer/float register communication, allowing data transfer between integer and float registers without performing any type conversion.

**Operation:**
```
E3 = <operand>  (least significant 32 bits of D3)
```

**Key Characteristics:**
- Integer/float register communication (no type conversion)
- Loads LSW (least significant word) of D3
- Essential for constructing 64-bit double float values
- Paired with A3:= to build complete D3 register
- Can transfer integer to float register directly
- 2-4 cycles (fastest with register source)
- Sets Z and S flags based on loaded value
- Used for double-precision bit manipulation
- No type conversion (bitwise transfer only)

When a register is specified as an operand, the general integer registers (I1-I4) are used. Thus, this instruction can transfer data between integer and float registers directly.

The double float registers D1-D4 are 64-bit registers, composed of a most significant part (A1-A4) and least significant part (E1-E4). This instruction loads only the least significant 32 bits.

**Operands:** 1
**Variants:** 1 opcode(s)

## Operands

### Operand 1 (Source)

The source operand containing the 32-bit word to load into the least significant part of D3 (E3).

**Type:** Word (32-bit)
**Access:** Read

**Supported modes:**
- **LOCAL** - Local data area access (B.variable)
- **RECORD** - Record-relative access (R.field)
- **CONSTANT** - Immediate constant value
- **REGISTER** - Integer register (I1-I4)
- **PRE_INDEXED** - Indexed addressing with offset
- **ABSOLUTE** - Absolute memory address

---

## Trap Conditions

- **Addressing traps:** Invalid address, descriptor range violation, page fault, protection violation

---

## Data Status Bits

- **Z (Zero):** Set if source operand = 0, cleared otherwise
- **S (Sign):** Set to sign bit of source operand (bit 31)
- **O (Overflow):** Unaffected
- **K (Flag):** Unaffected
- **C (Carry):** Unaffected

---

## Examples

### Example 1: Load from local variable

```assembly
        % Load E3 from local word
        E3:= B.MANTISSA_LOW
```

### Example 2: Load from integer register

```assembly
        % Transfer I4 to E3 without conversion
        E3:= I4
```

### Example 3: Construct double float

```assembly
        % Build D3 from two 32-bit values
        A3:= B.EXP_SIGN       % Most significant part
        E3:= B.MANTISSA       % Least significant part
```

### Example 4: Load immediate

```assembly
        % Load E3 with constant
        E3:= 0ABCDEF01H       % Specific bit pattern
```

---

## Performance Notes

- **Typical cycles:** 2-4 cycles depending on addressing mode
- **Best case:** 2 cycles (register to register)
- **Worst case:** 4+ cycles (memory access with page fault)
