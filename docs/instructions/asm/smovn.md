# SMOVN - String Move N Elements

**Mnemonic:** `smovn`  
**Function:** Move n string elements  
**Class:** STRING  
**Format:** `SMOVN <count>`

**Description:** Moves specified number of string elements.

**Examples:**

```assembly
% Copy n bytes
SMOVN 100
```

**Reference:** §14.7 String move m elements  
**See Also:** [SMOVE](smove.md)
