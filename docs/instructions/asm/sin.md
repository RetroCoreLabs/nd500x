# SIN - Sine

**Mnemonic:** `sin`  
**Function:** Sine function  
**Class:** MATH  
**Format:** `Fn SIN`

**Description:** Calculates sine of angle in register (radians).

**Examples:**

```assembly
% Calculate sine
F1 := B.ANGLE
F1 SIN
```

**Reference:** §12.5 Sine
