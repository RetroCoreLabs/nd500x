# COS - Cosine

**Mnemonic:** `cos`  
**Function:** Cosine function  
**Class:** MATH  
**Format:** `Fn COS`

**Description:** Calculates cosine of angle in register (radians). Result replaces register contents.

**Examples:**

```assembly
% Calculate cosine
F1 := B.ANGLE
F1 COS
```

**Reference:** §12.7 Cosine  
**See Also:** [SIN](sin.md), [TAN](tan.md)
