# DDIRT - Ddirt

## Overview

**Mnemonic:** `ddirt`
**Function:** Ddirt
**Class:** SYSTEM
**Privilege:** user

**Format:** `DDIRT`

---

## Description

Data marked 'dirty' in the data cache is written to the memory. If no cache is present, the instruction has no effect.

**Operands:** 0
**Variants:** 1 opcode(s)
