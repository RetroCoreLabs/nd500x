# SREGBL - Sregbl

## Overview

**Mnemonic:** `sregbl`
**Function:** Sregbl
**Class:** SYSTEM
**Privilege:** user

**Format:** `{prefix}{register} SREGBL <op1>,<op2>`

## Description
