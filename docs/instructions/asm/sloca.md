# SLOCA - String Locate

**Mnemonic:** `sloca`  
**Function:** Locate character in string  
**Class:** STRING  
**Format:** `SLOCA`

**Description:** Locates character in string.

**Examples:**

```assembly
% Find character
SLOCA
```

**Reference:** §14.15 String locate element
