# A3:= - Load Most Significant Part of Double Float Register A3

## Overview

**Mnemonic:** `a3:=`
**Function:** Load most significant part of double float register A3
**Class:** MOVE
**Privilege:** user

**Format:** `A3:= <operand>`

---

## Description

Loads the most significant 32 bits of the double float register A3 from the specified operand. This instruction is used for integer/float register communication, allowing data transfer between integer and float registers without performing any type conversion.

When a register is specified as an operand, the general integer registers (I1-I4) are used. Thus, this instruction can transfer data between integer and float registers directly.

Note that a float register (A1-A4) is equivalent to the most significant part of a double float register (D1-D4), so A3:= loads the entire float register A3.

**Operands:** 1
**Variants:** 1 opcode(s)

## Operands

### Operand 1 (Source)

The source operand containing the 32-bit word to load into the most significant part of A3.

**Type:** Word (32-bit)
**Access:** Read

**Supported modes:**
- **LOCAL** - Local data area access (B.variable)
- **RECORD** - Record-relative access (R.field)
- **CONSTANT** - Immediate constant value
- **REGISTER** - Integer register (I1-I4)
- **PRE_INDEXED** - Indexed addressing with offset
- **ABSOLUTE** - Absolute memory address

---

## Trap Conditions

- **Addressing traps:** Invalid address, descriptor range violation, page fault, protection violation

---

## Data Status Bits

- **Z (Zero):** Set if source operand = 0, cleared otherwise
- **S (Sign):** Set to sign bit of source operand (bit 31)
- **O (Overflow):** Unaffected
- **K (Flag):** Unaffected
- **C (Carry):** Unaffected

---

## Examples

### Example 1: Load from local variable

```assembly
        % Load A3 from local word variable
        A3:= B.FACTOR
```

### Example 2: Load from integer register

```assembly
        % Transfer I2 to A3 without conversion
        A3:= I2
```

### Example 3: Load from array element

```assembly
        % Load A3 from indexed array element
        A3:= B.COEFFICIENTS(I4)
```

### Example 4: Load immediate value

```assembly
        % Load A3 with bit pattern
        A3:= 040800000H        % Specific float bit pattern
```

---

## Performance Notes

- **Typical cycles:** 2-4 cycles depending on addressing mode
- **Best case:** 2 cycles (register to register)
- **Worst case:** 4+ cycles (memory access with page fault)
