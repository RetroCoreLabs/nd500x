# A2=: - Store Most Significant Part of Double Float Register A2

## Overview

**Mnemonic:** `a2=:`
**Function:** Store most significant part of double float register A2
**Class:** MOVE
**Privilege:** user

**Format:** `A2=: <operand>`

---

## Description

Stores the most significant 32 bits of the double float register A2 to the specified operand. This instruction is used for integer/float register communication, allowing data transfer between integer and float registers without performing any type conversion.

**Operation:**
```
<operand> = A2  (most significant 32 bits of D2)
```

**Key Characteristics:**
- Integer/float register communication (no type conversion)
- Stores MSW (most significant word) of D2
- Can transfer float to integer register directly
- Essential for register save/restore operations
- 2-4 cycles (fastest with register destination)
- Sets Z and S flags based on stored value
- Used for saving float registers before calls
- No type conversion (bitwise transfer only)
- Paired with A2:= for save/restore sequences

When a register is specified as an operand, the general integer registers (I1-I4) are used. Thus, this instruction can transfer data between float and integer registers directly.

Note that a float register (A1-A4) is equivalent to the most significant part of a double float register (D1-D4), so A2=: stores the entire float register A2.

**Operands:** 1
**Variants:** 1 opcode(s)

## Operands

### Operand 1 (Destination)

The destination operand where the 32-bit most significant part of A2 will be stored.

**Type:** Word (32-bit)
**Access:** Write

**Supported modes:**
- **LOCAL** - Local data area access (B.variable)
- **RECORD** - Record-relative access (R.field)
- **REGISTER** - Integer register (I1-I4)
- **PRE_INDEXED** - Indexed addressing with offset
- **ABSOLUTE** - Absolute memory address

**Note:** CONSTANT mode is not allowed for destination operands.

---

## Trap Conditions

- **Addressing traps:** Invalid address, descriptor range violation, page fault, protection violation
- **Illegal operand specifier (IOS):** Attempting to use constant as destination

---

## Data Status Bits

- **Z (Zero):** Set if source register A2 = 0, cleared otherwise
- **S (Sign):** Set to sign bit of source register A2 (bit 31)
- **O (Overflow):** Unaffected
- **K (Flag):** Unaffected
- **C (Carry):** Unaffected

---

## Examples

### Example 1: Store to local variable

```assembly
        ; Store A2 to local word variable
        A2=: B.TEMP_VALUE
```

### Example 2: Store to integer register

```assembly
        ; Transfer A2 to integer register I4 (no conversion)
        A2=: I4
```

### Example 3: Store to array

```assembly
        ; Store A2 to array element indexed by I2
        A2=: B.RESULTS(I2)
```

### Example 4: Save/restore around subroutine

```assembly
        ; Save A2 before call
        A2=: B.SAVE_A2
        CALL MODIFY_FLOAT_REGS
        A2:= B.SAVE_A2         ; Restore after call
```

---

## Performance Notes

- **Typical cycles:** 2-4 cycles depending on addressing mode
- **Best case:** 2 cycles (register to register)
- **Worst case:** 4+ cycles (memory access with page fault)
