# SFILLN - String Fill N Elements

**Mnemonic:** `sfilln`  
**Function:** Fill n string elements  
**Class:** STRING  
**Format:** `SFILLN <count>`

**Description:** Fills n string elements with value.

**Examples:**

```assembly
% Fill 100 bytes
SFILLN 100
```

**Reference:** §14.9 String fill n elements  
**See Also:** [SFILL](sfill.md)
