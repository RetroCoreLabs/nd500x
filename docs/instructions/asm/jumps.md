# JUMPS - Jumps

## Overview

**Mnemonic:** `jumps`
**Function:** Jumps
**Class:** BRANCH
**Privilege:** user

**Format:** `{prefix}{register} JUMPS <operand>`

---

## Description

Save P and B register in context block. Execution is started in `<address>`. The instruction implies SOLO mode. W1 returns the ND-500/ND-5000 CPU number.

**Operands:** 1
**Variants:** 1 opcode(s)
