# SMOVE - String Move

**Mnemonic:** `smove`  
**Function:** Move string  
**Class:** STRING  
**Format:** `SMOVE`

**Description:** Moves string from source to destination.

**Examples:**

```assembly
% Copy string
SMOVE
```

**Reference:** §14 String instructions
