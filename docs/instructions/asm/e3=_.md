# E3=: - Store Least Significant Part of Double Float Register E3 (D3)

## Overview

**Mnemonic:** `e3=:`
**Function:** Store least significant part of double float register D3 (E3)
**Class:** MOVE
**Privilege:** user

**Format:** `E3=: <operand>`

---

## Description

Stores the least significant 32 bits of the double float register D3 (referred to as E3) to the specified operand. This instruction is used for integer/float register communication, allowing data transfer between integer and float registers without performing any type conversion.

**Operation:**
```
<operand> = E3  (least significant 32 bits of D3)
```

**Key Characteristics:**
- Integer/float register communication (no type conversion)
- Stores LSW (least significant word) of D3
- Can transfer float to integer register directly
- Essential for decomposing 64-bit double values
- 2-4 cycles (fastest with register destination)
- Sets Z and S flags based on stored value
- Paired with A3=: to extract complete D3 register
- No type conversion (bitwise transfer only)
- Used for double-precision bit extraction

When a register is specified as an operand, the general integer registers (I1-I4) are used. Thus, this instruction can transfer data between float and integer registers directly.

The double float registers D1-D4 are 64-bit registers, composed of a most significant part (A1-A4) and least significant part (E1-E4). This instruction stores only the least significant 32 bits.

**Operands:** 1
**Variants:** 1 opcode(s)

## Operands

### Operand 1 (Destination)

The destination operand where the 32-bit least significant part of D3 (E3) will be stored.

**Type:** Word (32-bit)
**Access:** Write

**Supported modes:**
- **LOCAL** - Local data area access (B.variable)
- **RECORD** - Record-relative access (R.field)
- **REGISTER** - Integer register (I1-I4)
- **PRE_INDEXED** - Indexed addressing with offset
- **ABSOLUTE** - Absolute memory address

**Note:** CONSTANT mode is not allowed for destination operands.

---

## Trap Conditions

- **Addressing traps:** Invalid address, descriptor range violation, page fault, protection violation
- **Illegal operand specifier (IOS):** Attempting to use constant as destination

---

## Data Status Bits

- **Z (Zero):** Set if source register E3 = 0, cleared otherwise
- **S (Sign):** Set to sign bit of source register E3 (bit 31)
- **O (Overflow):** Unaffected
- **K (Flag):** Unaffected
- **C (Carry):** Unaffected

---

## Examples

### Example 1: Store to local variable

```assembly
        % Store E3 to local word
        E3=: B.LSW_DATA
```

### Example 2: Store to integer register

```assembly
        % Transfer E3 to integer register I2 (no conversion)
        E3=: I2
```

### Example 3: Extract double float parts

```assembly
        % Split D3 into two separate words
        A3=: B.UPPER          % Store most significant
        E3=: B.LOWER          % Store least significant
```

### Example 4: Write to record field

```assembly
        % Store E3 to record field
        E3=: R.MANTISSA_FIELD
```

---

## Performance Notes

- **Typical cycles:** 2-4 cycles depending on addressing mode
- **Best case:** 2 cycles (register to register)
- **Worst case:** 4+ cycles (memory access with page fault)
