# A2:= - Load Most Significant Part of Double Float Register A2

## Overview

**Mnemonic:** `a2:=`
**Function:** Load most significant part of double float register A2
**Class:** MOVE
**Privilege:** user

**Format:** `A2:= <operand>`

---

## Description

Loads the most significant 32 bits of the double float register A2 from the specified operand. This instruction is used for integer/float register communication, allowing data transfer between integer and float registers without performing any type conversion.

**Operation:**
```
A2 = <operand>  (most significant 32 bits of D2)
```

**Key Characteristics:**
- Integer/float register communication (no type conversion)
- Loads MSW (most significant word) of D2
- A2 register equivalent to MSW of D2 (float register)
- Can transfer integer to float register directly
- Essential for register restore and bit manipulation
- 2-4 cycles (fastest with register source)
- Sets Z and S flags based on loaded value
- Used for restoring float registers after calls
- No type conversion (bitwise transfer only)

When a register is specified as an operand, the general integer registers (I1-I4) are used. Thus, this instruction can transfer data between integer and float registers directly.

Note that a float register (A1-A4) is equivalent to the most significant part of a double float register (D1-D4), so A2:= loads the entire float register A2.

**Operands:** 1
**Variants:** 1 opcode(s)

## Operands

### Operand 1 (Source)

The source operand containing the 32-bit word to load into the most significant part of A2.

**Type:** Word (32-bit)
**Access:** Read

**Supported modes:**
- **LOCAL** - Local data area access (B.variable)
- **RECORD** - Record-relative access (R.field)
- **CONSTANT** - Immediate constant value
- **REGISTER** - Integer register (I1-I4)
- **PRE_INDEXED** - Indexed addressing with offset
- **ABSOLUTE** - Absolute memory address

---

## Trap Conditions

- **Addressing traps:** Invalid address, descriptor range violation, page fault, protection violation

---

## Data Status Bits

- **Z (Zero):** Set if source operand = 0, cleared otherwise
- **S (Sign):** Set to sign bit of source operand (bit 31)
- **O (Overflow):** Unaffected
- **K (Flag):** Unaffected
- **C (Carry):** Unaffected

---

## Examples

### Example 1: Load from local variable

```assembly
        ; Load A2 from local word variable
        A2:= B.COEFFICIENT
```

### Example 2: Load from integer register

```assembly
        ; Transfer I3 to A2 without conversion
        A2:= I3
```

### Example 3: Load from array element

```assembly
        ; Load A2 from array element
        A2:= B.ARRAY(I1)
```

### Example 4: Load constant bit pattern

```assembly
        ; Load A2 with specific bit pattern
        A2:= 03F800000H        ; Bit pattern for float 1.0
```

---

## Performance Notes

- **Typical cycles:** 2-4 cycles depending on addressing mode
- **Best case:** 2 cycles (register to register)
- **Worst case:** 4+ cycles (memory access with page fault)
