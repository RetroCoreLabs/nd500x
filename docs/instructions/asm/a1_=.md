# A1:= - Load Most Significant Part of Double Float Register A1

## Overview

**Mnemonic:** `a1:=`
**Function:** Load most significant part of double float register A1
**Class:** MOVE
**Privilege:** user

**Format:** `A1:= <operand>`

---

## Description

Loads the most significant 32 bits of the double float register A1 from the specified operand. This instruction is used for integer/float register communication, allowing data transfer between integer and float registers without performing any type conversion.

**Operation:**
```
A1 = <operand>  (most significant 32 bits of D1)
```

**Key Characteristics:**
- Integer/float register communication (no type conversion)
- Loads MSW (most significant word) of D1
- A1 register equivalent to MSW of D1 (float register)
- Can transfer integer to float register directly
- Essential for register restore and bit manipulation
- 2-4 cycles (fastest with register source)
- Sets Z and S flags based on loaded value
- Used for restoring float registers after calls
- No type conversion (bitwise transfer only)

When a register is specified as an operand, the general integer registers (I1-I4) are used. Thus, this instruction can transfer data between integer and float registers directly.

Note that a float register (A1-A4) is equivalent to the most significant part of a double float register (D1-D4), so A1:= loads the entire float register A1.

**Operands:** 1
**Variants:** 1 opcode(s)

## Operands

### Operand 1 (Source)

The source operand containing the 32-bit word to load into the most significant part of A1.

**Type:** Word (32-bit)
**Access:** Read

**Supported modes:**
- **LOCAL** - Local data area access (B.variable)
- **RECORD** - Record-relative access (R.field)
- **CONSTANT** - Immediate constant value
- **REGISTER** - Integer register (I1-I4)
- **PRE_INDEXED** - Indexed addressing with offset
- **ABSOLUTE** - Absolute memory address

---

## Trap Conditions

- **Addressing traps:** Invalid address, descriptor range violation, page fault, protection violation

---

## Data Status Bits

- **Z (Zero):** Set if source operand = 0, cleared otherwise
- **S (Sign):** Set to sign bit of source operand (bit 31)
- **O (Overflow):** Unaffected
- **K (Flag):** Unaffected
- **C (Carry):** Unaffected

---

## Examples

### Example 1: Load from local variable

```assembly
        ; Load most significant part of A1 from local word variable
        A1:= B.FPVALUE
```

### Example 2: Load from integer register

```assembly
        ; Transfer integer register I1 to float register A1 (no conversion)
        A1:= I1
```

### Example 3: Load from record field

```assembly
        ; Load A1 from field in record pointed to by R register
        A1:= R.MSW_VALUE
```

### Example 4: Load immediate constant

```assembly
        ; Load A1 with bit pattern representing float value
        A1:= 040000000H        ; Load specific bit pattern
```

---

## Performance Notes

- **Typical cycles:** 2-4 cycles depending on addressing mode
- **Best case:** 2 cycles (register to register)
- **Worst case:** 4+ cycles (memory access with page fault)
