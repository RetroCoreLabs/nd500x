# A4=: - Store Most Significant Part of Double Float Register A4

## Overview

**Mnemonic:** `a4=:`
**Function:** Store most significant part of double float register A4
**Class:** MOVE
**Privilege:** user

**Format:** `A4=: <operand>`

---

## Description

Stores the most significant 32 bits of the double float register A4 to the specified operand. This instruction is used for integer/float register communication, allowing data transfer between integer and float registers without performing any type conversion.

**Operation:**
```
<operand> = A4  (most significant 32 bits of D4)
```

**Key Characteristics:**
- Integer/float register communication (no type conversion)
- Stores MSW (most significant word) of D4
- Can transfer float to integer register directly
- Essential for register save/restore operations
- 2-4 cycles (fastest with register destination)
- Sets Z and S flags based on stored value
- Used for saving float registers before calls
- No type conversion (bitwise transfer only)
- Paired with A4:= for save/restore sequences

When a register is specified as an operand, the general integer registers (I1-I4) are used. Thus, this instruction can transfer data between float and integer registers directly.

Note that a float register (A1-A4) is equivalent to the most significant part of a double float register (D1-D4), so A4=: stores the entire float register A4.

**Operands:** 1
**Variants:** 1 opcode(s)

## Operands

### Operand 1 (Destination)

The destination operand where the 32-bit most significant part of A4 will be stored.

**Type:** Word (32-bit)
**Access:** Write

**Supported modes:**
- **LOCAL** - Local data area access (B.variable)
- **RECORD** - Record-relative access (R.field)
- **REGISTER** - Integer register (I1-I4)
- **PRE_INDEXED** - Indexed addressing with offset
- **ABSOLUTE** - Absolute memory address

**Note:** CONSTANT mode is not allowed for destination operands.

---

## Trap Conditions

- **Addressing traps:** Invalid address, descriptor range violation, page fault, protection violation
- **Illegal operand specifier (IOS):** Attempting to use constant as destination

---

## Data Status Bits

- **Z (Zero):** Set if source register A4 = 0, cleared otherwise
- **S (Sign):** Set to sign bit of source register A4 (bit 31)
- **O (Overflow):** Unaffected
- **K (Flag):** Unaffected
- **C (Carry):** Unaffected

---

## Examples

### Example 1: Store to local variable

```assembly
        % Store A4 to local word variable
        A4=: B.RESULT_VALUE
```

### Example 2: Store to integer register

```assembly
        % Transfer A4 to integer register I1 (no conversion)
        A4=: I1
```

### Example 3: Store to array element

```assembly
        % Store A4 to indexed array element
        A4=: B.OUTPUT_ARRAY(I2)
```

### Example 4: Save float state

```assembly
        % Preserve A4 before subroutine call
        A4=: B.SAVED_A4
        CALL FLOAT_ROUTINE
        A4:= B.SAVED_A4         % Restore A4
```

---

## Performance Notes

- **Typical cycles:** 2-4 cycles depending on addressing mode
- **Best case:** 2 cycles (register to register)
- **Worst case:** 4+ cycles (memory access with page fault)
