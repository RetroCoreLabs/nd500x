# A3=: - Store Most Significant Part of Double Float Register A3

## Overview

**Mnemonic:** `a3=:`
**Function:** Store most significant part of double float register A3
**Class:** MOVE
**Privilege:** user

**Format:** `A3=: <operand>`

---

## Description

Stores the most significant 32 bits of the double float register A3 to the specified operand. This instruction is used for integer/float register communication, allowing data transfer between integer and float registers without performing any type conversion.

**Operation:**
```
<operand> = A3  (most significant 32 bits of D3)
```

**Key Characteristics:**
- Integer/float register communication (no type conversion)
- Stores MSW (most significant word) of D3
- Can transfer float to integer register directly
- Essential for register save/restore operations
- 2-4 cycles (fastest with register destination)
- Sets Z and S flags based on stored value
- Used for saving float registers before calls
- No type conversion (bitwise transfer only)
- Paired with A3:= for save/restore sequences

When a register is specified as an operand, the general integer registers (I1-I4) are used. Thus, this instruction can transfer data between float and integer registers directly.

Note that a float register (A1-A4) is equivalent to the most significant part of a double float register (D1-D4), so A3=: stores the entire float register A3.

**Operands:** 1
**Variants:** 1 opcode(s)

## Operands

### Operand 1 (Destination)

The destination operand where the 32-bit most significant part of A3 will be stored.

**Type:** Word (32-bit)
**Access:** Write

**Supported modes:**
- **LOCAL** - Local data area access (B.variable)
- **RECORD** - Record-relative access (R.field)
- **REGISTER** - Integer register (I1-I4)
- **PRE_INDEXED** - Indexed addressing with offset
- **ABSOLUTE** - Absolute memory address

**Note:** CONSTANT mode is not allowed for destination operands.

---

## Trap Conditions

- **Addressing traps:** Invalid address, descriptor range violation, page fault, protection violation
- **Illegal operand specifier (IOS):** Attempting to use constant as destination

---

## Data Status Bits

- **Z (Zero):** Set if source register A3 = 0, cleared otherwise
- **S (Sign):** Set to sign bit of source register A3 (bit 31)
- **O (Overflow):** Unaffected
- **K (Flag):** Unaffected
- **C (Carry):** Unaffected

---

## Examples

### Example 1: Store to local variable

```assembly
        % Store A3 to local word variable
        A3=: B.OUTPUT
```

### Example 2: Store to integer register

```assembly
        % Transfer A3 to integer register I3 (no conversion)
        A3=: I3
```

### Example 3: Store to array

```assembly
        % Store A3 to array element
        A3=: B.BUFFER(I1)
```

### Example 4: Preserve register during computation

```assembly
        % Save A3 during complex calculation
        A3=: B.TEMP_A3
        % ... other float operations ...
        A3:= B.TEMP_A3         % Restore
```

---

## Performance Notes

- **Typical cycles:** 2-4 cycles depending on addressing mode
- **Best case:** 2 cycles (register to register)
- **Worst case:** 4+ cycles (memory access with page fault)
