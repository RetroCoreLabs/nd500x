# EXP - Exponential

**Mnemonic:** `exp`  
**Function:** e^x exponential  
**Class:** MATH  
**Format:** `Fn EXP`

**Description:** Calculates e raised to power in register.

**Examples:**

```assembly
% Calculate e^x
F1 := B.EXPONENT
F1 EXP
```

**Reference:** §12.12 Exponential
