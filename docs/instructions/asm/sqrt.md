# SQRT - Square Root

**Mnemonic:** `sqrt`  
**Function:** Square root  
**Class:** MATH  
**Format:** `Fn SQRT`

**Description:** Calculates square root of value in register.

**Examples:**

```assembly
% Calculate square root
F1 := B.VALUE
F1 SQRT
```

**Reference:** §12.4 Square root
