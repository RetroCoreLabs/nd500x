# A1=: - Store Most Significant Part of Double Float Register A1

## Overview

**Mnemonic:** `a1=:`
**Function:** Store most significant part of double float register A1
**Class:** MOVE
**Privilege:** user

**Format:** `A1=: <operand>`

---

## Description

Stores the most significant 32 bits of the double float register A1 to the specified operand. This instruction is used for integer/float register communication, allowing data transfer between integer and float registers without performing any type conversion.

**Operation:**
```
<operand> = A1  (most significant 32 bits of D1)
```

**Key Characteristics:**
- Integer/float register communication (no type conversion)
- Stores MSW (most significant word) of D1
- A1 register equivalent to MSW of D1 (float register)
- Can transfer float to integer register directly
- Essential for register save/restore and bit manipulation
- 2-4 cycles (fastest with register destination)
- Sets Z and S flags based on stored value
- Used for preserving float registers across calls
- No type conversion (bitwise transfer only)

When a register is specified as an operand, the general integer registers (I1-I4) are used. Thus, this instruction can transfer data between float and integer registers directly.

Note that a float register (A1-A4) is equivalent to the most significant part of a double float register (D1-D4), so A1=: stores the entire float register A1.

**Operands:** 1
**Variants:** 1 opcode(s)

## Operands

### Operand 1 (Destination)

The destination operand where the 32-bit most significant part of A1 will be stored.

**Type:** Word (32-bit)
**Access:** Write

**Supported modes:**
- **LOCAL** - Local data area access (B.variable)
- **RECORD** - Record-relative access (R.field)
- **REGISTER** - Integer register (I1-I4)
- **PRE_INDEXED** - Indexed addressing with offset
- **ABSOLUTE** - Absolute memory address

**Note:** CONSTANT mode is not allowed for destination operands.

---

## Trap Conditions

- **Addressing traps:** Invalid address, descriptor range violation, page fault, protection violation
- **Illegal operand specifier (IOS):** Attempting to use constant as destination

---

## Data Status Bits

- **Z (Zero):** Set if source register A1 = 0, cleared otherwise
- **S (Sign):** Set to sign bit of source register A1 (bit 31)
- **O (Overflow):** Unaffected
- **K (Flag):** Unaffected
- **C (Carry):** Unaffected

---

## Examples

### Example 1: Store to local variable

```assembly
        ; Store most significant part of A1 to local word variable
        A1=: B.RESULT
```

### Example 2: Store to integer register

```assembly
        ; Transfer float register A1 to integer register I2 (no conversion)
        A1=: I2
```

### Example 3: Store to record field

```assembly
        ; Store A1 to field in record pointed to by R register
        A1=: R.MSW_FIELD
```

### Example 4: Save float register before subroutine call

```assembly
        ; Preserve A1 value by storing to local area
        A1=: B.SAVED_A1
        CALL SUBROUTINE
        A1:= B.SAVED_A1        ; Restore after call
```

---

## Performance Notes

- **Typical cycles:** 2-4 cycles depending on addressing mode
- **Best case:** 2 cycles (register to register)
- **Worst case:** 4+ cycles (memory access with page fault)
