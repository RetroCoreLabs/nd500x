# PADDR - Paddr

## Overview

**Mnemonic:** `paddr`
**Function:** Paddr
**Class:** ARITHMETIC
**Privilege:** user

**Format:** `{prefix}{register} PADDR <operands>`

---

## Description

The `<a>` operand is added to the `<b>` operand and the sum is stored in the `<c>` operand. The result is scaled according to the scale factor in the `<c>` operand before storing.

**Operands:** 3
**Variants:** 1 opcode(s)
