# TAN - Tangent

**Mnemonic:** `tan`  
**Function:** Tangent function  
**Class:** MATH  
**Format:** `Fn TAN`

**Description:** Calculates tangent of angle in register (radians).

**Examples:**

```assembly
% Calculate tangent
F1 := B.ANGLE
F1 TAN
```

**Reference:** §12.9 Tangent  
**See Also:** [SIN](sin.md), [COS](cos.md)
