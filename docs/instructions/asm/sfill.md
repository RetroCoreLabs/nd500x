# SFILL - String Fill

**Mnemonic:** `sfill`  
**Function:** Fill string with value  
**CLASS:** STRING  
**Format:** `SFILL`

**Description:** Fills string with specified value.

**Examples:**

```assembly
% Fill with zeros
SFILL
```

**Reference:** §14.9 String fill n elements  
**See Also:** [SFILLN](sfilln.md)
