# E1=: - Store Least Significant Part of Double Float Register E1 (D1)

## Overview

**Mnemonic:** `e1=:`
**Function:** Store least significant part of double float register D1 (E1)
**Class:** MOVE
**Privilege:** user

**Format:** `E1=: <operand>`

---

## Description

Stores the least significant 32 bits of the double float register D1 (referred to as E1) to the specified operand. This instruction is used for integer/float register communication, allowing data transfer between integer and float registers without performing any type conversion.

**Operation:**
```
<operand> = E1  (least significant 32 bits of D1)
```

**Key Characteristics:**
- Integer/float register communication (no type conversion)
- Stores LSW (least significant word) of D1
- E1 register is lower 32 bits of 64-bit D1
- Can transfer float to integer register directly
- Essential for double float splitting and manipulation
- 2-4 cycles (fastest with register destination)
- Sets Z and S flags based on stored value
- Paired with A1=: to extract both halves of D1
- No type conversion (bitwise transfer only)

When a register is specified as an operand, the general integer registers (I1-I4) are used. Thus, this instruction can transfer data between float and integer registers directly.

The double float registers D1-D4 are 64-bit registers, composed of a most significant part (A1-A4) and least significant part (E1-E4). This instruction stores only the least significant 32 bits.

**Operands:** 1
**Variants:** 1 opcode(s)

## Operands

### Operand 1 (Destination)

The destination operand where the 32-bit least significant part of D1 (E1) will be stored.

**Type:** Word (32-bit)
**Access:** Write

**Supported modes:**
- **LOCAL** - Local data area access (B.variable)
- **RECORD** - Record-relative access (R.field)
- **REGISTER** - Integer register (I1-I4)
- **PRE_INDEXED** - Indexed addressing with offset
- **ABSOLUTE** - Absolute memory address

**Note:** CONSTANT mode is not allowed for destination operands.

---

## Trap Conditions

- **Addressing traps:** Invalid address, descriptor range violation, page fault, protection violation
- **Illegal operand specifier (IOS):** Attempting to use constant as destination

---

## Data Status Bits

- **Z (Zero):** Set if source register E1 = 0, cleared otherwise
- **S (Sign):** Set to sign bit of source register E1 (bit 31)
- **O (Overflow):** Unaffected
- **K (Flag):** Unaffected
- **C (Carry):** Unaffected

---

## Examples

### Example 1: Store to local variable

```assembly
        % Store E1 (least significant part of D1) to local word
        E1=: B.LSW_RESULT
```

### Example 2: Store to integer register

```assembly
        % Transfer E1 to integer register I3 (no conversion)
        E1=: I3
```

### Example 3: Extract double float to two words

```assembly
        % Split D1 into two separate 32-bit words
        A1=: B.MSW            % Store most significant part
        E1=: B.LSW            % Store least significant part
```

### Example 4: Save E1 state

```assembly
        % Preserve E1 before computation
        E1=: B.SAVED_E1
        % ... computation that modifies D1 ...
        E1:= B.SAVED_E1       % Restore
```

---

## Performance Notes

- **Typical cycles:** 2-4 cycles depending on addressing mode
- **Best case:** 2 cycles (register to register)
- **Worst case:** 4+ cycles (memory access with page fault)
