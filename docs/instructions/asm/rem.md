# REM - Remainder

**Mnemonic:** `rem`  
**Function:** Modulo/remainder operation  
**Class:** ARITHMETIC  
**Format:** `tn REM <divisor>,<dividend>,<dest>`

**Description:** Computes remainder of division.

**Examples:**

```assembly
% Get remainder
W REM B.VALUE, 10, B.REMAINDER
```
